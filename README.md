## 🚀 Running Locally

To run the portfolio website on your local machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yeshrutha/Portfolio.git
   cd Portfolio
   ```

2. **Serve the project:**
   You can serve the folder using any local development server:
   - **VS Code:** Install the **Live Server** extension, open the repository, and click `Go Live`.
   - **Python 3:**
     ```bash
     python -m http.server 8000
     ```
     Then navigate to `http://localhost:8000`.
   - **NodeJS/NPM:**
     ```bash
     npx serve .
     ```
